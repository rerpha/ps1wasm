OpenBIOS - open-source PlayStation BIOS replacement
====================================================

openbios.bin is OpenBIOS from the PCSX-Redux project:
  source:  https://github.com/pcsx-redux/nugget/tree/main/openbios
  docs:    https://pcsx-redux.consoledev.net/openbios/

Copyright (c) 2019 PCSX-Redux authors. Distributed under the MIT licence;
see LICENSE.txt in this folder (the licence of the nugget repository,
which PCSX-Redux's LICENSES.md names as OpenBIOS's licence).

It is NOT Sony's BIOS and contains no Sony code. Like other replacement
BIOSes it embeds the text "Licensed by Sony Computer Entertainment Inc."
because software checks for that string.

This binary was taken unmodified from a PCSX-Redux development build
(Linux AppImage, resources/openbios.bin).
